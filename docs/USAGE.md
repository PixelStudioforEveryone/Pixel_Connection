# 内网与服务器远程使用

## 同一内网：无需购买云服务器

一台 Windows／Linux 启动本地账号与信令服务，其他设备填写分享窗口的两条地址。各端登录同一服务器的同一账号，加入设备列表，选择在线 PC 并输入被控端验证码，即可进入桌面；文件传输可独立打开。

账号／信令连接服务主机，画面和文件通常由两端 P2P 直传。记录服务主机的 IP、API 和信令地址；换电脑登录填写服务器地址，不填自己电脑／手机的 IP 或 `127.0.0.1`。

示例 API `http://192.168.1.10:29910`，信令 `ws://192.168.1.10:9910`，需换成实际地址且两端可互通。服务主机保持运行，并放行这两个 TCP 端口。

## 不同网络：自建公网服务

按 [服务器构建文档](SERVER_BUILD.md)部署后端、HTTPS／WSS 网关及 TURN UDP。三端填写同一组公开 API、信令和 TURN 凭据。先检查登录和设备在线，再验证画面、键鼠、剪贴板和双向文件。

外网可直连时数据不经中继；无法穿透 NAT 时使用 TURN。账号／信令可达不保证远控通道可达。服务器、域名及带宽／流量费用由部署者承担。

## 平台差异

- Windows／Linux 均可主控、被控和提供本机服务器。
- 鸿蒙手机／大屏当前只做主控；进入鸿蒙设备桌面入口禁用，文件传输可用。
- 鸿蒙提供触摸、虚拟鼠标、系统键盘和分页电脑键盘；大屏采用与 PC 类似的悬浮控制中心。
- 剪贴板支持纯文本；鸿蒙系统读取需操作官方粘贴控件授权。

## 常见问题

**换服务器后账号无法登录？** 后端账号库彼此独立，需在新服务器注册，或迁移原账号库。

**地址不同却登录同一账号？** 可能是同一后端的回环、内网和公网入口，健康接口的服务器 ID 可确认。

**同内网仍不能连接？** 检查地址、防火墙、设备同账号在线、Wi-Fi／校园网客户端隔离。当前并非无服务器广播发现模式。

**锁屏或桌面未启动？** 平台桌面会话、采集与输入权限会影响远控，按实际系统验证。

**是否免费？** 原创源码采用 GPL-3.0-only，可自行构建部署；硬件、云资源、域名和流量成本自行承担。
